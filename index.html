How to Flash
1
Connect Nuetech Device with FTDI Programmer
Use a USB to Mini-B type cable to connect the FTDI programmer to your computer, then wire the FTDI to your Nuetech device as follows:
FTDI Programmer Pin Nuetech Device Pin
RX → TX
TX → RX
GND → GND
⚠️ Important: The jumper pin on the FTDI programmer must be set to 3.3V logic level before connecting. Setting it to 5V may permanently damage your Nuetech device.
🖼️ View reference image: FTDI 3.3V jumper & pinout →
2
Open Flash Website & Click Connect
Go to the Nuetech Device Flash Website, then click the Connect button above. A browser dialog will appear — select the correct COM port corresponding to your connected Nuetech device.

Tip: Use Google Chrome or Microsoft Edge for best compatibility. If no port appears, check your USB cable and FTDI driver installation.
3
Enter Programming Mode via Logs & Console
After connecting, a pop-up will appear. Click Logs & Console.

Then on the Nuetech device:
① Hold the EN button on the device
② While holding EN, turn OFF then ON the device using the Nuetech Power ON/OFF button

You should see the following output in the Console, confirming the device is in Programming Mode:
rst:0x1 (POWERON_RESET),boot:0x3(DOWNLOAD_BOOT(UART0/UART1/SDIO_REI_REO_V2))
waiting for download
✓ This output confirms the device is now in Programming Mode and ready to be flashed.
4
Install Firmware & Wait for Completion
Click the Back button in the pop-up. You will now see the Connecting… pop-up. Click Install Nuetech Firmware (the current firmware version will be shown alongside).

The flashing process will begin. Wait until the progress reaches 100% and you receive a Successful pop-up.
⚠️ Do NOT turn OFF the device during this process, and ensure there are no loose connections between the device and your laptop/computer. Any interruption may corrupt the firmware.
5
Restart Device & Verify via Console
After the Successful pop-up appears, click Next. Then click Logs & Console again.

Now turn OFF and then ON the Nuetech device using the Power ON/OFF button to let it boot with the new firmware.

You should see the following output in the Console, confirming the device is firmware updated:

6
Change Device Name via AT Command
To assign a unique name to the device, click the > arrow input field in the Logs & Console panel and type the appropriate AT command:
AT+NAME=ND-2
— or —
AT+NAME=ND-3
Note: Assign the device number based on the Total Installation count shown at the top of this page. For example, if this is the 3rd installation, use AT+NAME=ND-3.
